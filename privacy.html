Privacy Policy

Last updated: 23 November 2026

"The Long Ago Uploader" is an internal application used only by the owner of the YouTube channel The Long Ago. It is not offered to the public.

YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy at https://policies.google.com/privacy.

Information we access, use and store

With the channel owner's consent given through Google OAuth, the application uses the YouTube Data API only to upload videos, thumbnails and captions to the owner's own channel and to set their privacy status and publishing schedule. It reads only the owner's own channel identity (channels.list, mine=true) to confirm the account.

It does not collect, store, sell or share personal data of any other person, and it does not read viewers' data, comments or analytics. No data is shared with third parties. No cookies or tracking are used.

Storage

The only stored item is the owner's OAuth refresh token, kept encrypted as a secret in the owner's private GitHub repository. Video files are the channel's own content.

Data deletion and revoking access

Access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored token stops working and is deleted from the repository secrets within 7 days. To request deletion of any stored data, contact us via the channel's About page; requests are completed within 7 days.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Via the contact options on the YouTube channel's About page.
