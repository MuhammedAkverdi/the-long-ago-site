Privacy Policy

Last updated: 23 November 2026

"The Long Ago Uploader" is an internal application used only by the owner of the YouTube channel The Long Ago. It is not offered to the public.

What data the application uses

The application uses the YouTube Data API only to upload videos, thumbnails and captions to the owner's own channel and to set their publishing schedule. It accesses only the channel owner's account, with the owner's consent given through Google OAuth.

It does not collect, store, sell or share personal data of any other person. It does not read viewers' data, comments or analytics.

Storage

The OAuth refresh token is stored encrypted as a secret in the owner's private GitHub repository and is used only to perform the uploads described above.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API usage is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

Via the contact options on the YouTube channel's About page.
